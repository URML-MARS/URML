## What the heartbeat changed

PX4 v1.17 streams STATUSTEXT only on a MAVLink link where it has seen a `MAV_TYPE_GCS` heartbeat in the last 2.5 s (its STATUSTEXT stream checks `is_gcs_connected()` first). In the first record the adapter sent no heartbeat, so PX4 sent its link no STATUSTEXT. In this run the adapter's link on UDP 14540 received PX4's narration of the flight, from "Armed by external command" to "Landing detected" (the list in the pytest output above), and the e2e test now fails if that list is empty.

After the test closed the adapter, the heartbeat stopped, and PX4 logged "Connection to ground station lost" once `COM_DL_LOSS_T` (10 s by default) had passed. `NAV_DLL_ACT` is at its default, 0, so PX4 took no action; the vehicle was already on the ground and disarmed.

What it shows:

- **A, a take-off before PX4 was ready.** The probe connected right after PX4's first heartbeat, before PX4 printed "Ready for takeoff!". The arm was refused and the reason carried PX4's own text. Without the heartbeat PX4 sends the adapter's link no STATUSTEXT, and the same refusal read only `arm_rejected: mav_result_temporarily_rejected`. This case depends on connecting inside a window of a few seconds after boot; it did in all three probe sessions of the day.
- **B, a deterministic refusal.** With `COM_ARMABLE` = 0 (PX4's "disallow arming" parameter) the take-off was refused the same way. PX4 sent "Preflight Fail: Vehicle is in safety configuration" when the parameter changed, before the arm, and only "Arming denied: Resolve system health failures first" in reply to it. The adapter kept both texts and quoted only the one sent after its command, because it cannot tell whether an older warning still holds. The probe set `COM_ARMABLE` back to 1, and the session script restored PX4's parameter files from a copy taken before boot (the same md5 before and after).
- **C1, emergency_stop on a healthy vehicle** timed out after the 5 s it was given. The trigger the adapter used before this change, any `SYS_STATUS`, arrived 0.15 s into a second wait, so the old code would have reported an emergency stop on a vehicle that had none.
- **C2, emergency_stop after a flight termination.** The probe armed the vehicle on the ground (no take-off) and sent `MAV_CMD_DO_FLIGHTTERMINATION`. PX4's heartbeat switched to `system_status` 8, `MAV_STATE_FLIGHT_TERMINATION`, and `wait_for(emergency_stop)` fired 1.0 s later with `system_status: flight_termination`.

<details>
<summary>The probe script</summary>

Run from `reference/px4-runtime` with the URML venv's Python, right after PX4 SITL answers its first heartbeat. It uses the adapter's private helpers to send the arm and termination commands a URML program cannot.

```python
"""SITL probe for the heartbeat change: PX4's refusal text in URML's reasons, and emergency_stop.

Runs against a freshly booted PX4 v1.17.0 SITL (SIH). No flight is intended:
A tries a take-off before PX4 reports its pre-arm checks passing (lands again
if the checks passed in between), B refuses arming with COM_ARMABLE = 0 and
restores it, C checks wait_for(emergency_stop) on a healthy vehicle and after
a flight termination commanded on the ground.
"""

from __future__ import annotations

import struct
import time
from typing import Any

from pymavlink import mavutil

from urml_px4_runtime import PX4Adapter
from urml_px4_runtime.config import load_px4_config

PREARM = 0x10000000  # MAV_SYS_STATUS_PREARM_CHECK
MAV_CMD_COMPONENT_ARM_DISARM = 400
MAV_CMD_DO_FLIGHTTERMINATION = 185

T0 = time.monotonic()


def say(*args: Any) -> None:
    stamp = time.strftime("%H:%M:%S", time.gmtime())
    print(f"{stamp} +{time.monotonic() - T0:6.1f}s", *args, flush=True)


def prearm_ok(adapter: PX4Adapter, timeout: float = 3.0) -> bool | None:
    msg = adapter._connection.recv_match(type="SYS_STATUS", blocking=True, timeout=timeout)
    if msg is None:
        return None
    return bool(msg.onboard_control_sensors_health & PREARM)


def set_param_int(adapter: PX4Adapter, name: str, value: int) -> int | None:
    """PARAM_SET an INT32 (PX4 encodes it bytewise in the float field); return PX4's PARAM_VALUE."""
    conn = adapter._connection
    target_system, target_component = adapter._target_ids()
    as_float = struct.unpack("<f", struct.pack("<i", value))[0]
    with adapter._send_lock:
        conn.mav.param_set_send(
            target_system, target_component, name.encode(), as_float, mavutil.mavlink.MAV_PARAM_TYPE_INT32
        )
    deadline = time.monotonic() + 5.0
    while time.monotonic() < deadline:
        msg = conn.recv_match(blocking=True, timeout=1.0)
        if msg is None:
            continue
        adapter._observe(msg)  # keep any STATUSTEXT PX4 sends meanwhile
        if msg.get_type() == "PARAM_VALUE" and str(msg.param_id).rstrip("\x00") == name:
            return int(struct.unpack("<i", struct.pack("<f", msg.param_value))[0])
    return None


cfg = load_px4_config("tests/integration/px4_adapter_flight_only.yaml")
adapter = PX4Adapter(cfg)
say("connect:", adapter._begin() or "ok", "| heartbeat thread alive:", adapter._gcs_thread is not None and adapter._gcs_thread.is_alive())

# --- A: take off before PX4 reports its pre-arm checks passing -------------
ok_now = prearm_ok(adapter)
say("A pre-arm checks passing when the probe connected:", ok_now)
if ok_now is False:
    result = adapter.send_takeoff_goal(altitude=2.5)
    say("A take_off before ready:", result.success, repr(result.reason))
    if result.success:
        say("A checks passed in between; landing:", adapter.send_land_goal())
else:
    say("A skipped: PX4 already reported its pre-arm checks passing")

deadline = time.monotonic() + 120.0
while time.monotonic() < deadline and not prearm_ok(adapter):
    time.sleep(0.5)
say("pre-arm checks passing:", prearm_ok(adapter))

# --- B: COM_ARMABLE = 0, then take off ---------------------------------------
say("B COM_ARMABLE set, PX4 reports:", set_param_int(adapter, "COM_ARMABLE", 0))
adapter._listen(2.0)  # read (and keep) what PX4 says about the change
say("B STATUSTEXT so far:", [entry.text for entry in adapter._statustext_log])
result = adapter.send_takeoff_goal(altitude=2.5)
say("B take_off with COM_ARMABLE=0:", result.success)
say("B reason:", result.reason)
if result.success:
    say("B unexpected: armed; landing:", adapter.send_land_goal())
say("B COM_ARMABLE restored, PX4 reports:", set_param_int(adapter, "COM_ARMABLE", 1))
say("B armed after the refusal:", adapter._is_armed())

# --- C: emergency_stop ---------------------------------------------------------
started = time.monotonic()
result = adapter.wait_for_condition(
    kind="event", name="emergency_stop", input_mode=None, threshold=None, timeout_seconds=5.0
)
say(
    "C1 wait_for(emergency_stop) on a healthy, disarmed vehicle:",
    f"success={result.success} timed_out={result.timed_out} reason={result.reason!r}",
    f"after {time.monotonic() - started:.1f}s",
)
started = time.monotonic()
sys_status = adapter._connection.recv_match(type="SYS_STATUS", blocking=True, timeout=5.0)
say(
    "C1 the previous trigger, any SYS_STATUS, arrived after",
    f"{time.monotonic() - started:.2f}s" if sys_status is not None else "never",
)

time.sleep(1.0)
ok, reason = adapter._send_command_long(MAV_CMD_COMPONENT_ARM_DISARM, 1.0)
armed = adapter._await("HEARTBEAT", lambda m: bool(m.base_mode & 128), 5.0) is not None
say("C2 arm on the ground (no take-off):", ok, reason, "| armed:", armed)
ok, reason = adapter._send_command_long(MAV_CMD_DO_FLIGHTTERMINATION, 1.0)
say("C2 MAV_CMD_DO_FLIGHTTERMINATION:", ok, reason)
started = time.monotonic()
result = adapter.wait_for_condition(
    kind="event", name="emergency_stop", input_mode=None, threshold=None, timeout_seconds=10.0
)
say(
    "C2 wait_for(emergency_stop) after termination:",
    f"success={result.success} payload={result.payload} reason={result.reason!r}",
    f"after {time.monotonic() - started:.1f}s",
)
say("C2 last vehicle HEARTBEAT system_status:", getattr(adapter._heartbeat, "system_status", None))

texts = [f"[{entry.severity}] {entry.text}" for entry in adapter._statustext_log]
say("STATUSTEXT the adapter kept:", texts)
adapter.close()
say("closed; heartbeat thread:", adapter._gcs_thread)
```

## The CI recipe, rehearsed

The `px4-sitl-e2e` job in `.github/workflows/px4-integration.yml` was rewritten in this change to follow this recipe. Its steps were rehearsed from scratch in the same WSL2 machine, in a separate directory: a shallow, recursive clone of PX4-Autopilot `v1.17.0` with shallow submodules (it resolved to `d6f12ad`, the same commit), PX4's Python requirements in a new venv, and the build-only `make px4_sitl_default`, which exited 0 after about 8 minutes (10:10:00 to 10:18:18 UTC). The apt step ran as root rather than through sudo, and the GitHub-only steps (`GITHUB_ENV`, the artifact upload) were not exercised. GitHub has not run the job.

## Limits

- Simulation only, as in the first record: SIH physics, no wind, no sensor faults, no hardware.
- One program was flown. The probe exercised refusal reasons and `emergency_stop` outside a URML program, through the adapter's methods.
- PX4 v1.17 names the failing pre-arm check in a "Preflight Fail" STATUSTEXT when the check starts failing, and in its events interface (the MAVLink `EVENT` messages), which the adapter does not read. A reason quotes only what PX4 sent after the command, so for these refusals it carries the general "Arming denied" line, not the named check.
- The kill switch and the throw-launch lockdown, the other two sources of `MAV_STATE_FLIGHT_TERMINATION` in PX4 v1.17, were not exercised; flight termination was, on the ground.
- `NAV_DLL_ACT` was at its default, 0. What PX4 does when the heartbeat stops with it set (return, land, or another action) was not exercised here.
- Not CI. The workflow follows this recipe but has not run on GitHub.
